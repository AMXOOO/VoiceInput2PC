# VoiceInput2PC v0.4.0｜电脑文字可以取回手机

## 新功能

- Windows 接收端新增“发送剪贴板到手机”。
- 安卓端底部按指定顺序显示“新一段 / 开始输入到电脑 / 接收”。
- 手机点“接收”后，电脑文字直接进入原输入框，并保持暂停，不会自动回传电脑。
- 待接收文字和领取状态保存在电脑本机，连接仍使用 HTTPS、令牌和证书指纹固定。

## 使用方法

1. 在电脑任意程序中复制需要带到手机的文字。
2. 打开 Windows 接收端，点击“发送剪贴板到手机”。
3. 在安卓应用中点击最右侧“接收”。

本版本仍不传输音频、不申请安卓麦克风或相机权限，也不提供文件传输、后台推送或通知。
