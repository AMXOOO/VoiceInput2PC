VoiceInput2PC v0.3.0 使用说明

1. 解压 Windows 压缩包，双击 VoiceInput2PCReceiver.exe。
2. 首次启动时选择电脑地址，保持默认端口通常即可，然后生成配对码。
3. 安卓手机安装 APK。如果系统阻止安装，请只为当前文件临时允许“安装未知应用”。
4. 用手机系统相机扫描电脑二维码；也可复制完整配对码，在手机应用中粘贴后导入。
5. 在电脑上点中 Word、浏览器、Codex 或其他程序的输入位置。
6. 手机上点“开始输入到电脑”，再使用手机输入法自带的语音按钮。

说明：
- 手机与电脑需要能够互相访问；家庭中通常连接同一个 Wi-Fi 即可。
- 本程序不申请手机麦克风或相机权限。语音识别由你自己的手机输入法完成。
- 配对码相当于连接密码，请勿截图公开或发给不信任的人。
- Windows 程序目前未购买商业代码签名证书，首次运行可能出现系统提醒。
- 输入过程中不要切换电脑窗口；切换目标后请在手机上重新点“开始输入到电脑”。
