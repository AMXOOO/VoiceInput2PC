VoiceInput2PC v0.5.0 使用说明

1. 完整解压 Windows 压缩包，保留 `_internal` 文件夹，然后双击 VoiceInput2PCReceiver.exe。不要把 EXE 单独复制出来运行。
2. 首次启动时选择电脑地址，保持默认端口通常即可。
3. 安卓手机安装 APK。如果系统阻止安装，请只为当前文件临时允许“安装未知应用”。
4. 打开电脑端“配对手机”：
   - 手机与电脑在同一局域网：直接扫描默认二维码；
   - 不在同一网络：点击“跨网络配对”，再扫描新二维码。
5. 手机上用系统相机扫描二维码；也可以复制完整配对码，在应用中粘贴后导入。
6. 在电脑上点中 Word、浏览器、Codex 或其他程序的输入位置。
7. 手机上点“开始输入到电脑”，再使用手机输入法自带的语音按钮。
8. 需要把电脑文字发到手机时，先在电脑任意程序里复制文字，再打开接收端点击“发送剪贴板到手机”；手机点“接收”。

说明：
- 跨网络功能已经集成在 VoiceInput2PC 内部，不需要单独安装 Tailcat 或 Tailscale。
- 不要把 23337 端口直接暴露到公网。
- 本程序不申请手机麦克风或相机权限。语音识别由你自己的手机输入法完成。
- 二维码和完整配对码相当于连接密码；跨网络二维码还包含临时 Tailcat 连接地址。不要截图公开、发到群聊或粘贴到公开 Issue。
- Windows 程序目前未购买商业代码签名证书，首次运行可能出现系统提醒。
- 手动双击会显示窗口；开机自动启动时程序只驻留在系统托盘。
- 输入过程中不要切换电脑窗口；切换目标后请在手机上重新点“开始输入到电脑”。
- 回传只读取明确点击按钮时的文字剪贴板，不会后台监视剪贴板。
- 当前跨网络地址是临时连接凭据；Windows 接收端重启后，跨网络使用可能需要重新打开“跨网络配对”并扫码。
