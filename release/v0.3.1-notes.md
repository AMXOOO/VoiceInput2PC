# VoiceInput2PC v0.3.1｜Windows 启动修复版

本版本修复 Windows 接收端双击后看不到窗口的问题。

## 修复内容

- 首次启动时，设置窗口现在会直接显示在桌面上。
- 手动双击接收端时默认显示主窗口；只有开机启动才进入后台托盘模式。
- 程序已经运行时再次双击，会恢复并调出已有窗口。
- Windows 包改为更稳定的免安装目录包，避免受限电脑临时目录权限导致 Tcl/Tk 启动失败。
- 增加 Windows 文件版本信息，并停用 UPX 压缩。

## 使用方法

1. 下载 `VoiceInput2PC-Windows-v0.3.1.zip`。
2. 完整解压压缩包，保留 `_internal` 文件夹。
3. 双击 `VoiceInput2PCReceiver.exe`。不要把 EXE 单独复制出来运行。
4. 如果旧版仍在后台运行，请先在任务管理器结束旧版进程，再启动新版。

Android 端没有改动，继续使用 `VoiceInput2PC-Android-v0.3.0.apk`，协议与本版本兼容。

Windows 程序尚未购买商业代码签名证书，SmartScreen 可能显示提醒。请确认文件来自本仓库 Release，并使用 `SHA256SUMS.txt` 核对文件；不要关闭系统安全保护。公司设备如果被管理员策略禁止运行未签名程序，请联系 IT 管理员处理。
